## Publish on GitHub Pages

1. Create a public GitHub repository, for example `manish-portfolio`.
2. Upload **all files and folders** from this package into the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder.
6. Save.
7. Wait a few minutes. Your live site will appear at:
   - `https://yourusername.github.io/manish-portfolio/`
